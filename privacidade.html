Sobre este site

A Dentalis é uma clínica odontológica fictícia. Este site é um modelo demonstrativo criado pelo Estúdio Forja para mostrar como pode ser o site de uma clínica. Ele não agenda consultas, não presta atendimento e não vende serviços.

Quem é o responsável

O responsável por este site é o Estúdio Forja. Para qualquer assunto sobre privacidade, fale com o Estúdio pelo WhatsApp.

Que dados coletamos

Nenhum. O site não tem formulários que enviam dados, não pede cadastro, não usa cookies e não usa ferramentas de análise ou de publicidade. As fontes e as bibliotecas ficam no próprio site, sem chamar serviços de terceiros ao abrir a página.

Links para fora do site

  • Os botões "Quero um site assim" e "WhatsApp do Estúdio" abrem o WhatsApp, um serviço da Meta. A partir daí vale a política de privacidade do WhatsApp, e você só envia uma mensagem se quiser.
  • Os links "Estúdio Forja" e "Ver outros projetos" levam ao site do Estúdio Forja, que tem a sua própria política.

Seus direitos

Como este site não guarda dados pessoais, não há informações suas para consultar, corrigir ou apagar. Se você conversou com o Estúdio pelo WhatsApp, pode pedir a qualquer momento, pelo mesmo canal, que a conversa e os seus dados sejam apagados, conforme a Lei Geral de Proteção de Dados (Lei nº 13.709/2018).

Mudanças nesta política

Se o site passar a coletar algum dado, esta página será atualizada antes, com a nova data no topo.
